## 问题清单与证据

### 1. 编号断档、跳号、重复：未发现（低）

抽取 Markdown 文件名的数字前缀后排序，结果为 `docs/exam/2026年考点预测.md` 和真题 `2010` 至 `2025`。真题年份连续完整，重复年份 0、缺失年份 0；2026 是预测页，不属于真题序列。依据：`docs/exam/真题/2010年同等学力英语真题.md` 至 `docs/exam/真题/2025年同等学力英语真题.md`；`docs/exam/2026年考点预测.md`。文件名没有章节序号体系，因此不存在可据文件名前缀认定的章节跳号。

文内编号标题多为各自章节的局部列表并重新从 1 起算，不应误判为跨文件断号。例如 `docs/exam/高频语法与翻译.md:64-114` 与 `:146-173` 两组编号各自讲不同子题；这是局部重置，标题没有显式章节序号前缀。

### 2. 相同概念跨用途重复出现，导航边界需要说明（中）

- 词根学习分布于来源故事、速记和词族：`docs/roots.md:3,203` 链到 `docs/exam/词根词缀.md`，专题家族见 `docs/topic/词根家族.md:3`。三者目标不同（来源、考试速记、派生词族），交叉本身合理；若总览不标清差异，用户会难以选择入口。
- 时态和语法基础、专题对比、真题考法分在 `docs/tense.md:3,136-138`、`docs/topic/时态对比.md:3`、`docs/exam/高频语法与翻译.md:126-146`。页面已互链，说明现有分层有意，但搜索/侧栏仍可能把它们呈现成相似主题的多份材料。
- 发音系统页和面向中文学习者的难点页分于 `docs/pronunciation.md:1-5`、`docs/topic/发音难点.md:1-3`，前者系统讲音标，后者讲母语迁移错误；这是合理拆分，应在总览标出“系统课/问题专题”。

### 3. 命名风格存在小幅混用（低）

- 大小写不一：大部分页面为小写英文或中文名，唯一英文介绍为 `docs/english/Readme.md`（首字母大写，其余小写），而 `docs/topic/index.md` 用全小写 `index.md`。
- 语言和分隔符混用是目录分层的结果：导航和说明文件以中文命名（如 `docs/exam/考场时间分配.md`），实现/入口文件为英文名（如 `docs/index.md`、`docs/english/Readme.md`）；当前没有统一的全英文 slug 规则。
- 真题页遵循稳定、可排序的中文名加四位年份；其他考试文件按内容名称命名，预测页以 `2026年` 开头（`docs/exam/2026年考点预测.md`）。这是用途差异，不构成真题编号异常。

### 4. 侧边栏与文件对账：无失效配置，1 个页面未列入侧边栏（低）

数据源：`docs/.vitepress/config.mts`（加载 sidebar）及 `docs/.vitepress/sidebar.json`。解析得到 52 个唯一侧边栏链接。

| 对账方向 | 数量 | 条目 |
| --- | ---: | --- |
| 配置了但目标文件不存在 | 0 | 无 |
| 页面文件存在但未进侧边栏 | 1 | `docs/index.md`（作为首页 landing page，由 nav 的 `/` 与 VitePress 首页承载，不需要重复进侧栏） |

`docs/topic/index.md` 已由 `/topic/` 命中；`docs/SUMMARY.md` 不计未列项，因为 `docs/.vitepress/config.mts` 的 `srcExclude: ['**/SUMMARY.md']` 明确说明它是 mdbook 底稿而非页面。侧边栏有 52 项，真题按 2025 至 2010 倒序，符合近期优先阅读方式；不要仅为“全文件都列出”而增加首页或底稿。

### 5. 死链：构建验证通过，外链和锚点单独未核实（低）

首次构建因未安装依赖未启动；按锁文件执行 `npm ci` 后，`npm run docs:build` 成功，VitePress 完成页面渲染和 sitemap 生成，没有报告内部目标缺失/死链。构建仅出现客户端 chunk 大于 500 kB 的体积提示。该结果覆盖构建识别的站内 Markdown 链接，不等于外部网址可用性或每个片段锚点均已人工核实；外链与锚点状态：**未核实**。依据：构建命令及配置 `docs/.vitepress/config.mts`。

### 6. 根目录杂散文件与重复 README：有入口重复，非临时垃圾（低至中）

仓库根的 `README.md` 与 `README.zh.md` 是英文/中文版本，不是无差别重复；证据：两份文件顶部均有语言切换链接。`docs/english/Readme.md` 又有站点英文介绍，和根目录英文 README 在项目简介、内容入口上有重合；`docs/index.md` 还承担站点首页。结果是“仓库说明、站内首页、站内英文介绍”三个入口各自介绍项目，更新时有内容漂移风险（中，维护成本理由），但服务场景不同，删除/合并需先决定唯一受众定位。

除以上报告文件外，本次工作区没有发现其他未提交文件；跟踪的 Markdown 文件仅这些 README、站内页面和 `docs/SUMMARY.md`，未发现 `.tmp`、`.bak` 等临时 Markdown。`docs/SUMMARY.md` 是有明确注释的结构底稿，不是杂散文件。证据：仓库根 `README.md`、`README.zh.md`；`docs/english/Readme.md`；`docs/index.md`；`docs/SUMMARY.md:1-3`。

## 判断与推荐

### 严重度汇总

| 严重度 | 问题 | 理由 |
| --- | --- | --- |
| 中 | 词根、语法时态、发音等主题横跨学习/专题/备考用途 | 内容边界正确但相似标题易使读者误以为重复；先改入口说明和互链标签可降低查找成本 |
| 中 | 仓库 README、站内首页、英文介绍存在重复介绍 | 受众和入口不同，但重复段落需要同步，增加维护漂移可能 |
| 低 | `Readme.md` 大小写与其他文件命名不一致 | 单个例外，不影响当前侧边栏或构建；未来大小写敏感路径迁移时才有风险 |
| 低 | 首页文件未列在侧边栏 | 首页由路由和首页布局提供入口，属合理配置，不需修复 |
| 低 | 外链和锚点未独立检查 | 构建可确认站内路径基本可达，范围外项目仍未核实 |

整体结论：有 5 个内容组织轴，建议面向读者归并为 4 组入口；不是“目录乱”，而是多种学习/备考任务并存，加上介绍入口重复和局部命名差异。先收口导航说明与重复介绍的责任边界，不建议先移动文件或全盘改名。

### 其实不乱、不用动

- `docs/exam/真题/` 按年份连续组织 2010–2025，侧栏倒序便于先找最近年份；不要加章节编号或重排文件。
- `docs/topic/` 将一类问题独立成一页，并由 `docs/topic/index.md` 总览；这和根目录系统性知识页、`exam/` 应试分析有清晰教学用途差异。
- 根目录 `pronunciation.md`、`roots.md`、`history.md`、`timeline.md`、`grammar.md`、`tense.md` 等是核心学习笔记，按主题单页并通过交叉链接连接，适合保留。
- 侧边栏 52 个链接均有效；首页 `/` 由首页模板承载；`SUMMARY.md` 明确排除构建，作为 mdbook 底稿有说明，不是漏配。
- 根目录双 README 是中英文版本；不要把语言版本差异当成重复文件清理。

## 三期收口方案

| 阶段 | 动作清单 | 影响范围 | 风险（链接/搜索/外链） | 必须用户拍板 |
| --- | --- | --- | --- | --- |
| 一期：机械整理，目标 1 小时内 | 建立一份内容索引/入口说明，标清“系统学习、专题查疑、考点分析、真题练习”用途；在现有词根、时态、发音互链旁用短标签区分学习目标；统一新增文件命名约定（例如 README 大小写规则），不移动既有页面。 | `docs/index.md` 或 `docs/knowledge.md`、相关页面链接文字；未来新文件命名约定 | 极低；保留现有路径即可不打断站内链接、搜索索引或外链 | **入口说明放在首页还是知识总纲**需要拍板；建议首页只做导航，知识总纲放详细分类 |
| 二期：侧边栏与重定向 | 若用户决定把 `english/Readme.md` 作为独立文档保留，则完善英文入口链接；如改名/迁移，更新 `sidebar.json`、`SUMMARY.md`、站内链接并为旧 URL 配置重定向；同步核对 README 与首页入口分工。 | `docs/.vitepress/sidebar.json`、`docs/.vitepress/config.mts`、`docs/SUMMARY.md`、Markdown 链接及站点配置 | 中；更改 slug 会影响历史 URL、搜索结果和外链，需显式 redirect 并构建验证；仅调侧栏顺序不改 URL 风险低 | **是否保留站内英文介绍、是否调整其 URL/位置、侧栏分组排序**均需用户拍板 |
| 三期：内容删并深度重构 | 对照需求决定词根“来源/速记/词族”是否保留三种视角；评估时态/语法专题和考试分析重复段落，拆分“通用知识”与“真题统计”；对仓库 README、站内首页、英文介绍明确各自职责后删并冗余正文。 | `docs/roots.md`、`docs/topic/词根家族.md`、`docs/exam/词根词缀.md`、`docs/grammar.md`、`docs/tense.md`、相关专题与考试分析、三个介绍入口 | 高；删并可能改变搜索命中、锚点和页面内容，旧路径与外链均需保留或重定向，需逐页复核 | **所有删页、合并正文、改 URL、是否以考试备考为站点主轴**都必须用户拍板 |

## 结论：最该先做的三件事

1. 在首页或知识总纲补一张“按任务找内容”的入口图，明确系统学习、专题查疑、应试分析、历年练习的边界。
2. 给词根、时态/语法、发音的跨轴页面补清楚用途标签，保留三种内容视角但降低误认重复的概率。
3. 决定仓库 README、站内首页与 `docs/english/Readme.md` 的职责分工；分工确认后再做任何删并或迁移。
