# 词根家族

[词根来源](/roots)页讲每个词根的来历故事，本页看家谱：把一个词根的派生词全家列出，看核心义怎么在几十个词里反复出现。三个家族：spect（看）、duc/duct（引导）、fer（带来）。

## spect 家族：看

拉丁语 specere「看」。全家围绕一个「看」字，前缀定方向：

| 词 | 拆解 | 义 |
| --- | --- | --- |
| <SpeakButton word="inspect" text="inspect" /> | in-（往内）+ spect | 往里看 → 检查 |
| <SpeakButton word="respect" text="respect" /> | re-（反复）+ spect | 反复看在眼里 → 尊重 |
| <SpeakButton word="spectator" text="spectator" /> | spect + -ator（的人） | 看的人 → 观众 |
| <SpeakButton word="prospect" text="prospect" /> | pro-（向前）+ spect | 向前看到的景象 → 前景 |
| <SpeakButton word="suspect" text="suspect" /> | sus-（在下）+ spect | 在底下偷偷看 → 怀疑 |
| <SpeakButton word="perspective" text="perspective" /> | per-（透过）+ spect | 透过什么看 → 视角、透视 |
| <SpeakButton word="spectacle" text="spectacle" /> | spect + -acle | 拿来看的东西 → 景象、奇观（spectacles 是眼镜） |
| <SpeakButton word="retrospect" text="retrospect" /> | retro-（向后）+ spect | 回头看 → 回顾 |

希腊语的表亲是 scope 一族：telescope（tēle 远 + 看出 → 望远镜）、microscope（小 + 看 → 显微镜）。拉丁与希腊各留下一支「看」，见[词根来源](/roots#spect-看-拉丁-specere)。

## duc/duct 家族：引导

拉丁语 ducere「引导、带领」。词根定「带」这个动作，前缀定带往哪：

| 词 | 拆解 | 义 |
| --- | --- | --- |
| <SpeakButton word="educate" text="educate" /> | e-（出）+ duc | 把潜质引出来 → 教育 |
| <SpeakButton word="introduce" text="introduce" /> | intro-（向内）+ duc | 领进来 → 引进、介绍 |
| <SpeakButton word="produce" text="produce" /> | pro-（向前）+ duc | 带向前方 → 生产、产出 |
| <SpeakButton word="reduce" text="reduce" /> | re-（回）+ duc | 领回去 → 减少 |
| <SpeakButton word="conduct" text="conduct" /> | con-（一起）+ duct | 带着走 → 指挥；引申为「行为」 |
| <SpeakButton word="induce" text="induce" /> | in-（向内）+ duc | 引入、劝导 → 诱导 |
| <SpeakButton word="deduce" text="deduce" /> | de-（从…往下）+ duc | 从前提往下推 → 演绎 |
| <SpeakButton word="aqueduct" text="aqueduct" /> | aqua（水）+ duct | 引水的渠 → 渡槽 |

一个考点：induce 对应归纳（inductive reasoning，从具体到一般），deduce 对应演绎（deductive reasoning，从一般到具体），两个方向相反的推理各占一个前缀。

## fer 家族：带来

拉丁语 ferre「带来、承载」。全家是「把某物带往某处」，前缀定去向：

| 词 | 拆解 | 义 |
| --- | --- | --- |
| <SpeakButton word="transfer" text="transfer" /> | trans-（越过）+ fer | 带过距离 → 转移、换乘 |
| <SpeakButton word="refer" text="refer" /> | re-（回）+ fer | 带回去 → 提及、查阅 |
| <SpeakButton word="prefer" text="prefer" /> | pre-（在前）+ fer | 把…带在前面 → 偏爱 |
| <SpeakButton word="confer" text="confer" /> | con-（一起）+ fer | 带到一起 → 商讨；授予（confer a degree） |
| <SpeakButton word="suffer" text="suffer" /> | sub-（在下）+ fer | 在底下扛着 → 遭受、受苦 |
| <SpeakButton word="differ" text="differ" /> | dif-（分开）+ fer | 带向两边 → 不同 |
| <SpeakButton word="offer" text="offer" /> | ob-（向前）+ fer | 递到面前 → 提供 |
| <SpeakButton word="infer" text="infer" /> | in-（向内）+ fer | 从证据带入结论 → 推断 |
| <SpeakButton word="fertile" text="fertile" /> | fer 的形容词一支 | 能带来果实的 → 肥沃的 |

fer 与英语本族词 bear 是六千年前同一个印欧词（\*bher-「携带」），来历见[词根来源·fer](/roots#fer-带来-拉丁-ferre)。

## 家谱背法

先记核心义（看、引导、带来），再按前缀定方向：pro- 向前、re- 回、in- 向内、sub- 在下、trans- 越过。一个词拆不开时别硬拆，比如 suffer 已经离「带」很远，先记常用义，词源只当联想线索。
