# Roots and affixes quick-recall

> Word ≈ prefix (direction and range) + root (core meaning) + suffix (part of speech and class). Recognize the parts first, then memorize the word — even an unknown word can be split for a rough sense.
>
> This quick-recall and [High-frequency vocabulary](/exam/vocabulary) complement each other: roots and affixes solve "recognize the word, guess the word", and the high-frequency vocabulary page solves "synonymous replacement, word choice".
>
> To see which language these roots and affixes come from and how they evolved into today's words, read [Word roots](/roots) in the learning notes; to see the derived-word families of three roots, read [Root families](/topic/root-families). This page stays on quick-recall and word splitting.

## 1. The logic of word formation

1. **The root** decides the core meaning: words of the same root share one semantic core (the port family all relates to "carrying").
2. **The prefix** decides direction and range: ex- means "outward", so export is "carried out → export".
3. **The suffix** decides the part of speech: -tion is mostly a noun, -ly mostly an adverb. When reading, judge the part of speech by the suffix first, then guess the meaning by the root.

The complete breakdown I record: **transport** = trans- (across) + port (carry) → carried from one place to another → transport.

::: tip The three-step method for splitting words
① find the suffix and fix the part of speech; ② find the prefix and fix the direction; ③ fix the core meaning by the root, then put the word back into the sentence to verify.
:::

## 2. High-frequency roots (27)

| Root | Meaning | Example words | Breakdown of the examples |
| --- | --- | --- | --- |
| port | to carry, to convey | transport, export, import, portable | transport = trans- (across) + port → transport; export = ex- (outward) + port → export; import = im- (inward) + port → import; portable = port + able (capable of …) → able to be carried |
| duc/duct | to lead | conduct, produce, reduce, introduce, educate | conduct = con- (together) + duct → to lead / to conduct; produce = pro- (forward) + duce → to produce; reduce = re- (back) + duce → to reduce; introduce = intro- (inward) + duce → to introduce; educate = e- (outward) + duc → to educate (leading the potential in a person out) |
| spect/spic | to look | inspect, respect, prospect, suspect | inspect = in- (inward) + spect → looking in → to inspect; respect = re- (again) + spect → looking at repeatedly with weight → to respect; prospect = pro- (forward) + spect → looking ahead → prospect; suspect = sub- (under) + spect → looking askance → to suspect |
| dict/dic | to say, to speak | predict, dictionary, contradict, indicate | predict = pre- (before) + dict → saying before → to predict; dictionary = dict + ionary → the place where words are spoken → dictionary; contradict = contra- (opposite) + dict → saying against → to contradict; indicate = in- (pointing) + dic → pointing and explaining → to indicate |
| rupt | to break | interrupt, erupt, corrupt, bankrupt | interrupt = inter- (between) + rupt → breaking in the middle → to interrupt; erupt = e- (outward) + rupt → bursting out → to erupt; corrupt = cor- (strengthening) + rupt → the structure breaking down → corrupt; bankrupt = bank (bank) + rupt → the chain of funds breaking → bankruptcy |
| vis/vid | to look, to see | visible, vision, revise, provide, evidence | visible = vis + ible (capable of …) → able to be seen; vision = vis + ion → eyesight / far view; revise = re- (again) + vis → looking over again → to revise; provide = pro- (before) + vid → seeing ahead and making ready → to provide; evidence = e- (out) + vid + ence → able to be seen out → evidence |
| tract | to pull, to drag | attract, extract, contract, distract | attract = at- (toward) + tract → pulled to one point → to attract; extract = ex- (outward) + tract → pulled out → to extract; contract = con- (together) + tract → pulled together → contraction / contract; distract = dis- (apart) + tract → attention pulled away → to distract |
| graph/gram | to write, to draw | photograph, geography, telegraph, diagram | photograph = photo (light) + graph → "writing" an image with light → photograph; geography = geo (earth) + graph → depicting the earth → geography; telegraph = tele- (far) + graph → writing to a distance → telegraph; diagram = dia- (through) + gram → threading points through into a figure → diagram |
| scrib/script | to write | describe, manuscript, prescription, subscribe | describe = de- (down) + scrib → writing down → to describe; manuscript = manu (hand) + script → a text written by hand → manuscript; prescription = pre- (before) + script → usage written down in advance → prescription; subscribe = sub- (under) + scrib → signing at the bottom → to subscribe |
| mit/mis | to send | transmit, submit, mission, permit | transmit = trans- (across) + mit → sent to the other end → to transmit; submit = sub- (upward) + mit → sending the material up → to submit; mission = mis + ion → the thing one is sent out for → mission; permit = per- (through) + mit → letting pass → to permit |
| ject | to throw | reject, inject, project, object | reject = re- (back) + ject → thrown back → to reject; inject = in- (into) + ject → thrown into the body → to inject; project = pro- (forward) + ject → thrown forward → project / projection; object = ob- (against) + ject → thrown against → to object |
| posit/pose | to put, to place | deposit, position, compose, propose, postpone | deposit = de- (down) + posit → put down → deposit / sediment; position = posit + ion → the place it is put → position; compose = com- (together) + pose → put together → to compose; propose = pro- (forward) + pose → putting an idea forward → to propose; postpone = post- (later) + pon(e) → put later → to postpone |
| fer | to bring, to carry | transfer, prefer, refer, differ | transfer = trans- (across) + fer → carried to another place → to transfer; prefer = pre- (first) + fer → taken first → to prefer; refer = re- (back) + fer → carried back to check → to refer to; differ = dis- (apart) + fer → each carried its own way → to differ |
| sume/sumpt | to take, to seize | consume, assume, resume, presume | consume = con- (wholly) + sume → taken all away → to consume; assume = a- (toward) + sume → taken over → to assume / to take on; resume = re- (again) + sume → taken back again → to resume; presume = pre- (before) + sume → taking a mind for granted in advance → to presume |
| cur/curs | to run | occur, current, course, recur | occur = oc- (toward) + cur → running into view → to occur; current = cur + ent → that which is running → current / current of water; course = curs + e → the way that is run out → course / course of events; recur = re- (again) + cur → running back again → to recur |
| form | shape, form | transform, formal, information, reform | transform = trans- (change) + form → changing the shape → to transform; formal = form + al (of …) → conforming to form → formal; information = in- (making) + form + ation → arranging content into a form → information; reform = re- (again) + form → shaped anew → to reform |
| log/logue | to speak, learning | dialogue, biology, technology, psychology | dialogue = dia- (between) + logue → speaking between two → dialogue; biology = bio (life) + logy → the learning of life → biology; technology = techno (technique) + logy → the learning of technique → technology; psychology = psych (mind) + logy → the learning of the mind → psychology |
| chron | time | chronicle, chronology, synchronize, chronic | chronicle = chron + icle → recording by time → chronicle; chronology = chron + ology → studying the order of time → chronology; synchronize = syn- (at the same time) + chron + ize → aligning times → to synchronize; chronic = chron + ic → time dragging on long → chronic |
| path | feeling, disease | sympathy, empathy, apathy, pathology | sympathy = sym- (together) + path → a shared feeling → sympathy; empathy = em- (into) + path → going into another's feeling → empathy; apathy = a- (not) + path → having no feeling → apathy; pathology = path + ology → the learning of disease → pathology |
| gen | to produce, kind | generate, generation, genetic, genre | generate = gen + ate → brought forth → to generate; generation = gen + eration → the people born of the same batch → generation; genetic = gen + etic → relating to production and heredity → genetic; genre = gen + e → the division of the same kind → genre |
| vert/vers | to turn | convert, reverse, diverse, universal | convert = con- (wholly) + vert → turning over entirely → to convert; reverse = re- (back) + vers → turned back → to reverse; diverse = di- (apart) + vers → turned toward many directions → diverse; universal = uni- (one) + vers + al → holding where soever you turn → universal |
| ced/ceed/cess | to go | proceed, process, succeed, exceed, recession | proceed = pro- (forward) + ceed → going forward → to proceed; process = pro + cess → the going forward → process; succeed = suc- (following on) + ceed → going after → to succeed / to inherit; exceed = ex- (beyond) + ceed → stepping past the boundary → to exceed; recession = re- (back) + cess + ion → going backward → recession |
| ple/plen | full | complete, supplement, plenty, replenish | complete = com- (wholly) + ple → filled up → to complete; supplement = sup- (filling under) + ple + ment → filling the gap → to supplement; plenty = plen + ty → held very full → plenty; replenish = re- (again) + plen + ish → filled up again → to replenish |
| loc | place, position | local, locate, allocate, dislocate | local = loc + al → belonging to this place → local; locate = loc + ate → fixing the place → to locate; allocate = al- (toward) + locate → allotted to many places → to allocate; dislocate = dis- (away) + locate → out of its place → displacement / dislocation |
| memor | memory | memory, memorial, commemorate, memorize | memory = memor + y → what is held in mind → memory; memorial = memor + ial → used for remembering → memorial; commemorate = com- (together) + memor + ate → everyone remembering together → to commemorate; memorize = memor + ize → put into memory → to commit to memory |
| ven/vent | to come | prevent, event, adventure, convention | prevent = pre- (before) + vent → coming before → to prevent; event = e- (outward) + vent → what comes out → event; adventure = ad- (toward) + vent → the big thing that comes at you → adventure; convention = con- (together) + vent → everyone coming together → convention / custom |
| cap/capt | to seize, head | capture, capacity, capital, accept | capture = cap + ure → the seizing → capture; capacity = cap + acity → how much can be seized → capacity; capital = cap + ital → the "head" that ranks first → capital / capital city; accept = ac- (toward) + cept (a variant of cap) → reaching out and seizing → to accept |

## 3. High-frequency prefixes (20)

| Prefix | Meaning | Example words | Breakdown of the examples |
| --- | --- | --- | --- |
| pre- | before, beforehand | preview, predict, previous, prepare | preview = pre + view (look) → looking ahead → preview; predict = pre + dict (speak) → speaking beforehand → to predict; previous = pre + vious (way) → going ahead → previous; prepare = pre + par (ready) → made ready beforehand |
| re- | again, back | revise, return, replace, review | revise = re + vis (look) → looking over again → to revise; return = re + turn (turn) → turned back → to return; replace = re + place (place) → put back in place → to replace; review = re + view → looking over again → to review |
| un- | not, non-; also "undo, open" | unable, unfair, unusual, unlock | unable = un + able → not able; unfair = un + fair → unfair; unusual = un + usual → unusual; unlock = un + lock → undoing the lock → to unlock |
| dis- | negation, apart | disagree, disappear, discourage, discount | disagree = dis + agree → minds not meeting; disappear = dis + appear → no longer appearing → to disappear; discourage = dis + courage → courage drawn away → to discourage; discount = dis + count → struck off the number → discount |
| inter- | between, mutual | international, interview, interact, interchange | international = inter + national → between nations → international; interview = inter + view (look) → meeting face to face → interview; interact = inter + act → acting on one another; interchange = inter + change → exchanging with one another |
| trans- | across, change of form | transport, translate, transform, transfer | transport = trans + port (carry) → carried across a distance → to transport; translate = trans + late (carry) → the meaning carried to the other side → to translate; transform = trans + form (shape) → change of shape → to transform; transfer = trans + fer (carry) → carried to another place → to transfer |
| ex- | outward, former | export, expose, exclude, expect | export = ex + port (carry) → carried out → to export; expose = ex + pose (put) → put out → to expose; exclude = ex + clud (shut) → shut out of doors → to exclude; expect = ex + spect (look) → gazing into the distance → to expect |
| im-/in- | in, into; also negation "not" | import, inhabit, impossible, incorrect | import = im + port (carry) → carried in → to import; inhabit = in + habit (dwell) → dwelling inside → to inhabit; impossible = im + possible → impossible; incorrect = in + correct → incorrect |
| en-/em- | to make, to enter | enable, encourage, enrich, enlarge | enable = en + able → make able; encourage = en + courage → given courage → to encourage; enrich = en + rich → make rich → to enrich; enlarge = en + large → make larger → to enlarge |
| de- | down, away | decrease, decline, delete, descend | decrease = de + crease (growth) → going down → to decrease; decline = de + cline (slope) → sloping down → to decline; delete = de + lete (erase) → erased → to delete; descend = de + scend (climb) → climbing down → to descend |
| con-/com- | together, with | combine, connect, common, compare | combine = com + bin (two) → two into one → to combine; connect = con + nect (bind) → bound together → to connect; common = com + mun (share) → shared by all → common; compare = com + par (equal) → put together → to compare |
| ab-/abs- | away from | absent, abstract, absolute, abnormal | absent = ab- (away) + esse (be) → the person not being there → absent; abstract = abs + tract (pull) → the points pulled out → abstract; absolute = ab + solut (loosed) → bound by nothing → absolute; abnormal = ab + normal → away from the normal → abnormal |
| ad- (variants a-/af-/at-/as-) | toward, strengthening | attract, attend, assist, adjust | attract = at + tract (pull) → pulled toward one point → to attract; attend = at + tend (stretch) → stretched toward something → to attend / to attend to; assist = as + sist (stand) → standing beside → to assist; adjust = ad + just (right) → set to the right position → to adjust |
| sub- | under, secondary | submit, subway, submarine, subsequent | submit = sub + mit (send) → sent below → to submit; subway = sub + way (way) → a way under ground → subway; submarine = sub + marine (of the sea) → below the surface of the sea → submarine; subsequent = sub + sequ (follow) → following after → subsequent |
| super-/sur- | over, above | superior, surface, surpass, supreme | superior = super + ior (more) → a higher position → superior; surface = sur + face (face) → the upper layer → surface; surpass = sur + pass (pass over) → passed beyond → to surpass; supreme = super + (superlative) → as high as the top → supreme |
| under- | under, insufficient | underground, underestimate, undergo, undertake | underground = under + ground (ground) → below the ground; underestimate = under + estimate (estimate) → estimated too little → to underestimate; undergo = under + go (go) → passing through from below → to undergo; undertake = under + take (take) → taking the matter on → to undertake |
| mis- | wrongly | mistake, misunderstand, mislead, misspell | mistake = mis + take (take) → taken wrongly → mistake; misunderstand = mis + understand → understood wrongly; mislead = mis + lead (lead) → led on the wrong way → to mislead; misspell = mis + spell (spell) → spelled wrongly |
| auto- | self, automatic | automatic, automobile, autonomous, autobiography | automatic = auto + mat (self-moving) → moving of itself → automatic; automobile = auto + mobile (movable) → a car that moves of itself → automobile; autonomous = auto + nom (govern) → governing itself → autonomous; autobiography = auto + bio (life) + graph (write) → writing one's own life → autobiography |
| multi- | many | multiple, multimedia, multiply, multicultural | multiple = multi + ple (fold) → more than one fold → multiple; multimedia = multi + media (medium) → many media → multimedia; multiply = multi + ply (fold) → increasing fold upon fold → to multiply; multicultural = multi + cultural → holding many cultures together |
| mono- | single, one | monologue, monopoly, monotonous | monologue = mono + logue (speak) → one person speaking alone → monologue; monopoly = mono + pole (sell) → the only house selling → monopoly; monotonous = mono + ton(e) (tone) → only one tone → monotonous |

## 5. A note on use

- Word splitting is a **guessing means**, and the final check is to put the word back into the sentence. The modern sense of some common words has moved away from its etymology (as with describe and depart), so memorize the common sense first and use the etymology only as an association cue.
- The same root often has variants (duct/duc, vis/vid, posit/pose, ced/ceed/cess): the pronunciation changes, the spelling follows, the meaning stays.
- After splitting has given you the "rough direction", you still need the real-paper synonymous-replacement tables in [High-frequency vocabulary](/exam/vocabulary); the exam ultimately tests the precise sense in context.
