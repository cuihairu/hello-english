## 页首来源行体例（2026-10-10 核查）

各真题页标题下的引注块固定四类标签，按下列顺序出现，用词全站统一：

| 标签 | 必填 | 内容 |
| --- | --- | --- |
| 来源 | 必填 | 主来源链接清单（文字页、PDF、附件直链），多源以 `\|` 分隔 |
| 优先参考 | 必填 | 底本说明：以哪份来源为底本、据其补录了哪些部分、答案取自哪里 |
| 补充参考 | 可选 | 次要的交叉核对来源链接 |
| 核对说明 | 可选 | 核对、勘误、推导待核对、回忆版口径等注意事项 |

本次核查统一了旧标签：`主要参考`、`勘误说明`、`转录说明`、`回忆版说明`、`补充说明`、`核对结论` 分别并入 `优先参考` 与 `核对说明`；2015、2016、2017、2018 四页原缺 `优先参考`（页首未标答案可靠度），已按本表补齐；2013 页 `来源` 行补入卷二实际使用的新阳光两处链接；2020、2025 页调整为「优先参考在前、核对说明在后」。
