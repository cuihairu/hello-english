# 词根词缀速记

> 单词 ≈ 前缀（方向与范围）+ 词根（核心意义）+ 后缀（词性与类别）。先认构件，再记单词，遇到生词也能拆出大意。
>
> 本页与[高频词汇](高频词汇.md)互为补充：词根词缀解决「认词、猜词」，高频词汇页解决「同义替换、选词」。

## 一、构词逻辑

1. **词根**决定核心意义：同词根的词共享一个语义内核（如 port 家族都与「搬运」有关）。
2. **前缀**决定方向与范围：如 ex- 表「向外」，export 就是「运出去 → 出口」。
3. **后缀**决定词性：如 -tion 多为名词、-ly 多为副词。阅读时先用后缀判断词性，再用词根推测词义。

完整拆解示例：**transport** = trans-（跨越）+ port（搬运）→ 从一处搬到另一处 → 运输。

::: tip 拆词三步法
① 找后缀，定词性；② 找前缀，定方向；③ 词根定核心义，再放回原句验证。
:::

## 五、使用提醒

- 拆词是**猜测手段**，最终要放回原句验证。部分常用词的现代词义已与词源拉开距离（如 describe、depart），先记常用义，词源只作联想线索。
- 同一词根常有变体（duct/duc、vis/vid、posit/pose、ced/ceed/cess），读音变了、拼写跟着变，含义不变。
- 拆词认出「大致方向」后，仍需配合[高频词汇](高频词汇.md)里的真题同义替换表使用——考试考的是语境里的准确词义。
