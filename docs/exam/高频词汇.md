## 二、高频词汇统计

### 1. 按词性统计

统计样本共 148 题（2010-2012 仅计 Section A），其中：

| 类型 | 数量 | 占比 |
| --- | --- | --- |
| 单词词义辨析 | 108 | 73% |
| 短语/固定搭配辨析 | 40 | 27% |

在 108 道单词题中，名词最多（33 题），动词次之（31 题），形容词 24 题、副词 14 题；另有复合词性 3 题（slump、authorized、commuting）、介词 2 题（beyond、beneath）、连词 1 题（lest）：

| 类别 | 代表词 | 特点 |
| --- | --- | --- |
| 动词 | suspend, assess, surpass, consolidate, convert | 常考常见动词的近义替换 |
| 名词 | trait, liability, scrutiny, consensus, deficiency | 常考抽象名词和学术名词 |
| 形容词/副词 | fragile, deliberate, rigorous, sufficient, deliberately | 常考语气和程度判断 |

### 2. 已复现高频词

以下词或同义关系在已核实年份中出现 2 次及以上：

| 词汇/关系 | 出现情况 | 说明 |
| --- | --- | --- |
| eligible → qualified | 2016, 2025 | 资格类高频 |
| enough 类语义 | sufficient → enough；ample → enough | 数量充足类高频 |
| deliberate 族 | 2010, 2011, 2013, 2017 | “故意”考了四次：purposefully → deliberately、on purpose → deliberately、deliberate → intentional（2011、2017 两次同型） |
| surpass → exceed | 2010, 2016；transcend → exceed（2022） | “超过”高频，exceed 三度作正确选项 |
| comply with → observe | 2012, 2018 | 同一短语同型替换两次；observe 另在 2010 年作画线词（observe → follow） |
| remarks | 2012, 2023 | 同一画线词两次：remarks → speech / remarks → opinions |
| diminished | 2018, 2019 | 同一画线词两次：diminished → decreased / diminished → declined |
| perspective | 2021, 2022 | 2021 年作画线词（→ viewpoint），2022 年作正确选项（lens → perspective） |
| make up | 2013, 2019 | 一词两义：make up → compose（构成）、made it all up → invented（编造） |
| “大约”语义链 | 2011, 2012 | in the neighborhood of → approximately；approximately → roughly |
| “几乎不” | 2011, 2016 | scarcely → hardly；barely → hardly |
| stop 类语义 | ceased → stopped；suspend → halt；called off → canceled | “停止/取消”是稳定高频语义 |
| explain/show 类语义 | demonstrated → showed；elaborated → explained；put across → explain；interpretation → explanation | “解释/展示”类高频 |
| control/cause 类语义 | at the mercy of → under the control of；attributed to → caused by | 因果与支配关系常考 |
| large/more 类语义 | substantial → heavy；in excess of → more than | 程度与数量比较高频 |

### 3. 高频语义场

按语义归类，历年词汇题最常考的是以下几类：

| 语义场 | 代表题目 |
| --- | --- |
| 停止/取消 | cease, suspend, call off, wear off |
| 资格/适用性 | eligible, qualify, sufficient, ample |
| 解释/说明/展示 | demonstrate, elaborate, remarks, interpretation, trait |
| 因果/归因 | attribute to, give rise to, consist in |
| 态度/倾向 | reluctant, unwillingly, inclined, deliberate |
| 遵守/遵循 | observe → follow，comply with → observe（2012、2018 两次） |
| 限制/约束 | confined → restricted，trapped → caught，hold back → check |
| 超过/大约 | surpass → exceed，transcend → exceed，approximately → roughly |
| 程度/变化 | diminish, slump, deteriorate, beyond, virtually |

### 2. 需要重点掌握的“规定用法”

这些不是简单背中文意思，而是要连同搭配和语境一起记：

| 表达 | 规定用法 | 说明 |
| --- | --- | --- |
| eligible for | be eligible for sth. | 表“有资格获得/申请” |
| attribute A to B | attribute A to B | 表“把 A 归因于 B” |
| appeal to sb. | sth. appeal to sb. | 表“某事物吸引某人” |
| be authorized to do | be authorized to do sth. | 表“被授权做某事” |
| catch up with sth. | catch up with sth. | 表“跟上进度/理解已进行内容” |
| carry out a plan / task | carry out sth. | 表“执行计划、任务、调查” |
| call off a class / meeting | call off sth. | 表“取消活动” |
| give out information | give out sth. | 在真题里考“泄露信息”，不是“分发试卷” |
| in excess of | in excess of sth. | 表“超过……” |
| leaf through a book | leaf through sth. | 表“快速翻阅” |
| be inclined to | be inclined to do / toward sth. | 表“倾向于” |
| in terms of | in terms of sth. | 表“从……方面来说” |
| put across an idea / point | put across sth. | 表“把观点表达清楚” |
| consist in | consist in sth. / doing sth. | 表“在于”，不要和 consist of 混淆 |
| wear off | pain / effect wears off | 表“效果逐渐消退” |
| comply with | comply with rules / decisions | 表“遵守规则、裁决”，2012、2018 两次考到 |
| get down to sth. | get down to (doing) sth. | to 是介词，表“着手处理正事” |
| make way for | make way for sth. | 表“为……让路、腾出空间” |
| call for | call for sth. | 表“需要、要求”，等于 require |
| lean on sb. | lean on sb. = count on sb. | 表“依靠某人” |
| cling to sth. | cling to a belief / view | 表“坚持信念、观点不放” |
| under no circumstances | 句首用部分倒装：Under no circumstances should we… | 表“绝不”，语序是考点 |

### 3. 高频易混短语

| 真题表达 | 易混表达 | 区别 |
| --- | --- | --- |
| consist in | consist of | 前者是“在于”，后者是“由……组成” |
| give out | give off | 前者常指“分发/泄露/用尽”，后者是“发出（气味、热、光）” |
| call off | put off | 前者“取消”，后者“推迟” |
| carry out | work out | 前者“执行”，后者“算出/解决/锻炼” |
| catch up with | keep up with | 前者偏“追上进度/内容”，后者偏“保持同步” |
| in excess of | in need of | 前者表“超过”，后者表“需要” |
| turn out | make out | 前者可表“生产/结果是”，后者多表“辨认出/理解” |
| step down | slow down | 前者“下台/辞职”，后者“慢下来” |
| make up | make up for | 前者真题考过“构成”（→compose）和“编造”（→invent）两个义项，后者是“弥补” |
| as opposed to | in terms of | 前者“与……相对”（2010），后者“就……而言”（2017），都是介词短语但义不同 |
| under no circumstances | for no reason | 前者“决不”（句首倒装），后者“没有理由”，2021 年互为干扰项 |
| take after | take on | 前者“长得像/性格像”，后者“承担/雇用/呈现” |

## 四、备考结论

### 1. 词汇题不是单纯背单词

真题的核心是同义替换，但命题方式更偏向：

- 常见词换近义表达
- 短语换固定搭配
- 抽象义而不是字面义

### 2. 短语题占比稳定偏高

在当前已核实样本里，短语/固定搭配题占 27%。这意味着复习时不能只背单词表，必须同步记：

- 动词 + 介词/副词
- 固定搭配的常见宾语
- 易混短语之间的语义边界

### 3. 优先级建议

建议按下面顺序复习：

1. 停止/取消/变化类动词与短语
2. 因果/归因/说明类表达
3. 资格、倾向、态度类形容词和固定结构
4. 真题反复出现的短语搭配
