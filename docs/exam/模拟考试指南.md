# 模拟考试指南

> 基于 2010—2025 年共 16 份整理版真题与[考场时间分配](考场时间分配.md)的节奏基准整理，供自行组卷、评分与复盘使用。本指南不新编题目，全部使用仓内真题页；各卷来源与答案可靠度见各真题页页首与[真题来源核对](真题/真题来源核对.md)。

## 一、组卷原则

1. **全真优先**：整套模拟一律用真题，不自行拼题
2. **完整度决定用途**：题面与答案齐全的年份才作整套模拟，有缺口的卷子降级为分项练习（见下表）
3. **未精读过的年份优先作整套**；已精读过的作分项限时训练
4. **留最新的卷子压轴**：2023、2025 建议留作考前两周的全真模拟

## 三、评分表

每次模拟判分后填写：

| 部分 | 满分 | 得分 | 失分归因 |
|------|------|------|---------|
| 口语交际 | 10 | | |
| 词汇 | 10 | | |
| 阅读理解 | 25 | | |
| 完形填空 | 10 | | |
| 短文完成 | 20 | | |
| 翻译 | 10 | | |
| 写作 | 15 | | |
| **合计** | **100** | | |

**评分口径（本站建议）**：

- 客观题（口语、词汇、阅读、完形、短文完成）按各真题页文末参考答案判分
- 翻译对照参考译文按要点自评：语义准确与语句通顺并重，漏译、误译逐处标记
- 写作对照范文自评：是否覆盖题目要点、语言是否准确、结构是否完整；无范文的年份（2024）按[高频写作](高频写作.md)的框架与句型自评

## 四、复盘流程

1. 判分并填写评分表
2. 错题归因到对应分析页：词汇错→[高频词汇](高频词汇.md)、阅读错→[高频阅读](高频阅读.md)、口语错→[高频口语交际](高频口语交际.md)、完形与短文完成错→[高频完形与短文完成](高频完形与短文完成.md)、翻译与写作弱→[高频语法与翻译](高频语法与翻译.md)与[高频写作](高频写作.md)
3. 找出失分最多的两三个部分，下一周针对性训练后再模拟
4. 对照[考场时间分配](考场时间分配.md)的六个检查点核对用时，超时部分单独复盘

## 五、频次建议

- **备考中段**：每两周 1 套
- **考前一个月**：每周 1 套
- **考前两周**：用 2023、2025 作最后两套全真模拟，严格按 150 分钟与六个检查点执行

> **标注说明**：组卷、评分与复盘口径均为本站按仓内真题整理的备考建议，非官方考试说明；各卷答案可靠度不一，详见各真题页页首标注。
