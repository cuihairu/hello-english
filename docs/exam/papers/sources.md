## The page-head source-line convention (checked 2026-10-10)

The quote block under each past-paper title carries a fixed set of four labels, in this order, with site-wide wording:

| Label | Required | Content |
| --- | --- | --- |
| Source | Required | List of primary source links (text page, PDF, direct attachment links), several sources separated by `\|` |
| Primary reference | Required | The base-text statement: which source is the base, which parts were transcribed from it, and where the answers come from |
| Supplementary reference | Optional | Secondary cross-check source links |
| Verification note | Optional | Notes on checking, corrections, derived answers still to be verified, and the recollection-version caveat |

This pass unified the older labels: `main reference`, `correction note`, `transcription note`, `recollection-version note`, `supplementary note` and `verification conclusion` were folded into `Primary reference` and `Verification note` respectively; the four pages of 2015, 2016, 2017 and 2018 were missing `Primary reference` (the page head gave no answer-reliability statement) and it was added per the table above; the 2013 page's `Source` line gained the two Xinyangguang links actually used for Paper Two; the 2020 and 2025 pages were reordered to "primary reference first, verification note last".

The answer section keeps two source-line presentations, both traceable: **a parenthetical in the heading** (for example "reference answers (extracted from PDF)") and **a standalone `> Source:` line** (2016, 2017); single-source answers carry an extra note block (2015, 2022).
